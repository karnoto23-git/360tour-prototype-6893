# PT Vale Indonesia — Virtual Site Tour — Design

- Bahasa: Indonesia (lang="id"), seluruh teks UI dan data hardcoded.
- Warna: dominan hijau tua #0B2E26; aksen kuning #F2B705; latar terang #F4F7F5; mint #7FD1AE (info), biru #8ECAE6 (gambar), koral #F28482 (video).
- Font: Plus Jakarta Sans (400–800).
- Layout: landing full-bleed video; peta dengan masterplan + pin; tur full-screen viewer dengan bar atas (lokasi), bar bawah (pindah lokasi), kontrol kanan (zoom, layar penuh).
- Hotspot 3D: lingkaran berwarna + label; nav = kuning, info = mint, gambar = biru, video = koral.
- Popup: sheet bawah di mobile, modal tengah di desktop; tutup dengan tombol atau Esc.
